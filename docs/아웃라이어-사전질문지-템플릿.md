# 사전 질문지 양식 (운동과 건강함)

> 기준 예시: 박용택 원장(허리), 강형창 원장(암), 이진혁 원장(치매) 사전 질문지. 기획 직원은 이 양식을 그대로 따른다.
> 질문지 자체는 **전문가에게 보내는 문서**다. 아웃라이어 분석, 제목·썸네일 후보 같은 내부 메모는 질문지 위에 따로 두고, 질문지 본문에는 넣지 않는다.

## 노션 기획안 페이지 구성

```
[내부용 · 전문가에게 보내지 않음]
## 기반 아웃라이어 분석
- 영상: 제목 / 채널 / 업로드일 / 조회수 · 구독자 · 배수 (기반 영상은 업로드 1년 이내 + 채널 구독자 60만 미만이 확인된 것만)
- 왜 터졌나: 제목 구조 · 썸네일 워딩 · 첫 30초 후킹 · 질문 유형 · 출연자 권위 중 핵심 1~2개
- 가져올 것: (구조만. 문장은 베끼지 않는다)
- 버릴 것: (과장, 근거 약한 주장, 우리 채널과 안 맞는 부분)
- 우리 버전 각도: 같은 구조, 다른 질문 한 줄
- 추천 출연자: 기존 출연자 또는 「섭외 후보」 중 본인 유튜브 채널이 확인된 1~2명 + 이유 한 줄
## 제목 · 썸네일 후보 (부마다)
- 제목 2개 (서로 다른 클릭 포인트) / 썸네일 문구 1개 (2줄)
## 쇼츠 후보
- 쇼츠 첫 문장 3개 (어느 부, 어느 질문에서 나오는지)
## 의학 검수 메모
- 단정하면 안 되는 표현, 근거 확인이 필요한 수치

---

[전문가에게 보내는 질문지 · 아래 형식 그대로]
```

## 질문지 형식

```
<이름> 원장님 사전 질문지

N부 구성

● 1부 – <부 제목>
● 2부 – <부 제목>
● 3부 – <부 제목>
● 4부 – <부 제목>

진행 안내

● 보조 질문은 진행하지 않을 수도 있습니다. (예: Q.1-1, Q.2-2)
● 답변 도중 괜찮은 내용이 나오면 질문지에 없는 내용을 추가로 질문드릴 수도 있습니다.
● 예상 답변은 참고만 하시면 됩니다. 다른 내용으로 답해주셔도 전혀 상관없습니다!
● 일부 답변이 서로 겹치더라도 괜찮습니다.

1부
「<부 제목>」

1. <섹션 제목>
예시 자막: <영상에 들어갈 한 줄 자막>
Q.1 <본 질문>
Q.1-1 <보조 질문>
→ 예상 답변 : <핵심 1> / <핵심 2> / <핵심 3>

2. <섹션 제목>
...
```

암처럼 근거 조정이 필요한 주제는 진행 안내 마지막 줄을 이것으로 바꾼다:
`● 예시 자막과 제목 문구는 편집 과정에서 실제 답변과 의학적 근거에 맞춰 최종 조정할 예정입니다.`

## 규칙

**구성**
- 보통 4부, 부마다 섹션 5~8개. 1부 1번 섹션만 전문가 소개(질문 1개, 짧게). 2부부터는 소개 없이 바로 시작
- 부 제목은 그 자체로 영상 제목 후보: 질문형("~어디까지 좋아질 수 있을까?"), 조건+행동("~있다면, 이 운동 해보세요"), 숫자·기간("3개월 동안 바꿔야 할 것들"), 반전·물음("등 통증보다 먼저?")
- 부의 흐름: 원인·오해 → 구분·신호 → 해야 할 것 → 하지 말아야 할 것 → 병원 가야 하는 때 → 마지막 한 마디
- 각 부의 마지막 질문은 "마지막으로 ~하시는 분들에게 꼭 해주고 싶은 말씀" 또는 "오늘부터 딱 한 가지만 바꾼다면"

**섹션**
- 섹션 제목은 시청자 궁금증을 그대로 쓴다: "집에서 관리해도 되는 사람 vs 병원에 가야 하는 사람", "반드시 병원에 가야 하는 위험 신호"
- 예시 자막은 섹션마다 1줄. 썸네일·쇼츠 첫 문장으로 바로 쓸 수 있는 말투: "이 증상은 허리통증이라고 그냥 참으면 안 됩니다", "몇 분이나 걸을 수 있느냐가 중요합니다"
- 본 질문 Q.N 1개 + 보조 질문 Q.N-1, Q.N-2 0~3개

**질문 말투**
- 일반인이 하는 말로: "~많잖아요", "~많이 궁금해하시는데요", "원장님, ~"
- 흔한 통념을 먼저 꺼내고 묻는다: "딱딱한 바닥에서 자는 게 좋다는 이야기를 많이 하잖아요. 실제로도 ~?"
- 개수를 정해서 묻는다: "3가지만", "5가지 정도", "딱 한 가지"
- 실제 진료 경험·환자 사례·기준을 끌어낸다: "원장님이 실제 진료에서 중요하게 보는 기준", "좋아졌던 사례를 3가지 정도"
- 조합과 기준을 묻는다: "몇 개 정도 해당되면 병원을", "어떤 증상들이 함께 나타나면"

**자주 쓰는 질문 유형** (한 부에 3가지 이상 섞는다)
| 유형 | 예 |
|---|---|
| 오해 깨기 | "암세포는 설탕을 먹고 자란다"는 이야기가 많은데요. 어디까지가 사실이고 어디부터가 과장인가요? |
| 구분 | 집에서 관리해볼 수 있는 분과 병원 치료를 적극적으로 받아야 하는 분을 어떻게 구분할 수 있을까요? |
| 순위·개수 | 일반인이 놓치기 쉬운 췌장암의 대표적인 신호를 5가지 정도 꼽아주신다면? |
| 신호·위험 | 어떤 증상이 생기면 참지 말고 빨리 병원에 가야 하나요? |
| 하지 말 것 | 평소 많이 하지만 허리를 더 힘들게 만들 수 있는 자세나 생활습관은? |
| 행동·기간 | "딱 3개월만 제대로 해보자"고 한다면 무엇을 어떤 순서로? |
| 조합 | 여러 위험요인이 겹치면 각각 하나만 있을 때와는 다르게 봐야 하나요? |
| 사례 | 운동을 꾸준히 하면서 인지기능이 좋아진 사례가 있었나요? |
| 확인 지표 | "내 허리가 좋아지고 있구나"라고 스스로 확인할 수 있는 변화는? |

**예상 답변**
- `→ 예상 답변 : ` 뒤에 핵심을 ` / `로 나열. 문장이 아니라 키워드 묶음
- 모든 질문에 달 필요는 없다. 전문가가 방향을 잡기 어려운 질문에 단다
- 의학적으로 조심스러운 내용은 열어 둔다: "환자 상태에 따라 차이", "의료진이 판단", "치료를 대신하는 것이 아님"
- 근거가 불확실한 효능, 특정 제품, "완치" 같은 단정은 쓰지 않는다

**피할 것**
- 교과서 질문만으로 된 섹션("~은 무엇인가요?"는 섹션 첫 질문 정도로만, 바로 생활 질문으로 이어지게)
- 긴 전문가 소개, 한 부에 주제 여러 개, 핵심과 무관한 사족
- 아웃라이어 영상의 질문·문장을 그대로 옮기는 것
