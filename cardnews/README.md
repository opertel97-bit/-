# 매일 건강/다이어트 카드뉴스

`@officiald.kr` 톤을 기준으로 하는 **단일 포스트 포맷**입니다. (2026-07-19부터 적용)

## 포맷

각 날짜 폴더(`YYYY-MM-DD/post.md`)에 다음을 담습니다.

1. **오버레이 문구** — 사진(또는 합성 이미지) 위에 얹을 텍스트
   - 포스트잇/손글씨 스타일 짧은 키워드 1개
   - 하단 굵은 헤드라인 문장 (핵심 키워드 강조)
2. **이미지** — 실사 인물 사진 생성·스톡 소싱은 불가능하므로(이미지 생성 모델 접근 없음), 아래 둘 중 하나로 진행합니다.
   - 사용자가 그날 사진을 준다 → 그 사진 위에 오버레이 문구를 얹는 걸 전제로 문구만 제공
   - 사용자가 사진을 안 준다 → HTML/CSS + 헤드리스 브라우저 스크린샷으로 **플랫 일러스트 합성 이미지**(그라데이션 배경 + 실루엣 피규어 + 포스트잇 + 헤드라인까지 완성된 한 장)를 직접 만들어 제공. 예시: `2026-07-19/assets/example-card.png`
3. **캡션** — 후킹 질문 → 핵심 주장 → 실제 연구 인용(저자·연도·저널) → 기전 설명 → 추가 관점 → 주의/한계 문구 → 클로징 → `Reference:` 전체 출처

## 원칙

- 인용은 실제 존재하는 연구만 사용하고, 가능하면 검색으로 저자/저널/연도/PMID를 확인한 뒤 표기합니다.
- 과장된 의학적 주장은 지양하고, 연구의 한계(대상자 수, 특정 집단 등)를 캡션 안에 짧게라도 언급합니다.
- 주제는 매일 다르게 — 이전 날짜 폴더를 참고해 겹치지 않게 선정합니다.
