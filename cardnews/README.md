# 매일 건강/다이어트 카드뉴스

`@officiald.kr` 톤을 기준으로 하는 포맷입니다. (2026-07-19부터 적용)

## 포맷 — 하루 3개 포스트

각 날짜 폴더(`YYYY-MM-DD/post-1.md`, `post-2.md`, `post-3.md`)에 서로 다른 주제로 3개를 담습니다.
각 포스트는 다음 구조입니다.

1. **오버레이 문구** — 사진 위에 얹을 텍스트
   - 포스트잇 스타일 짧은 키워드 1개
   - 하단 굵은 헤드라인 문장 (핵심 수치/키워드 강조)
   - ⚠️ 사진 자체는 제공하지 않습니다. 실사 인물 사진 생성·스톡 이미지 소싱이 이 환경에서는 불가능하므로(이미지 생성 모델 접근 없음, 외부 스톡 API도 네트워크 정책상 차단됨), 매일 사용자가 준비한 사진 3장 위에 이 문구를 얹는 것을 전제로 합니다.
   - 사진이 없는 날을 위한 대체 옵션(플랫 일러스트 합성 이미지)은 `2026-07-19/assets/example-card.png` 참고 — 필요할 때만 사용.
2. **캡션** — 후킹 질문(이모지) → 핵심 주장 → 실제 연구 인용(저자·연도·저널, 괄호 인용) → 기전 설명 → 추가 관점 → 주의/한계 문구 → 클로징 한 줄 → `Reference:` 전체 출처(저자 전체·논문 제목·저널·연도·권(호)·페이지·PMID)

## 원칙

- 인용은 실제 존재하는 연구만 사용하고, 검색으로 저자/저널/연도/PMID를 확인한 뒤 표기합니다.
- 과장된 의학적 주장은 지양하고, 연구의 한계(대상자 수, 특정 집단, 소규모 실험 등)를 캡션 안에 짧게라도 언급합니다.
- 하루 3개 주제는 서로 겹치지 않게, 이전 날짜 폴더의 주제도 참고해 겹치지 않게 선정합니다.
