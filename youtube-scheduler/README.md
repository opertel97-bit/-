# 유튜브 쇼츠 자동 예약 · 설명란 해시태그 도구

스튜디오에 올려둔 **비공개 쇼츠**를 한 번에 정리합니다.

- 영상이 꼭 필요한 시청자에게 닿도록 **설명란 해시태그 · 검색 태그**를 Claude 가 작성
- **제목은 건드리지 않음** (`config.yaml` 의 `generate_title: true` 로 켤 때만 작성)
- 하루 N개, 정해진 시간(예: 18:00 / 20:00 / 22:00)으로 **예약 공개 자동 배정**
- 이미 예약된 쇼츠도 시간 재조정 가능
- 쇼츠마다 연결할 롱폼을 정리한 **'관련 동영상' 수동 연결 체크리스트** 생성

**공식 YouTube Data API 만 사용**합니다. 스튜디오 화면을 자동 클릭하지 않아요.
이 도구는 영상을 삭제하거나 다시 올리지 않고, 바로 공개로 돌리지도 않습니다. 예약은 항상 `비공개 + 예약 시간` 으로만 걸립니다.

> 쇼츠 → 롱폼 '관련 동영상' 연결은 공식 API 가 지원하지 않습니다. 그래서 자동으로 바꾸지 않고, `linklist` 명령으로 체크리스트만 만들어 줍니다. 실제 연결은 스튜디오에서 직접 하세요.

---

## 전체 흐름

```
fetch  →  (plan.csv 에 메모 · 롱폼 적기, 선택)  →  generate  →  schedule  →  check  →  apply  →  apply --execute  →  verify
가져오기        엑셀로 편집                         해시태그 작성   시간 배정    검사      미리보기    실제 반영           확인
```

모든 작업은 `plan.csv` 한 파일에서 이뤄집니다. 엑셀로 열어서 마음대로 고쳐도 됩니다.
`apply --execute` 전까지는 유튜브에 아무것도 바뀌지 않습니다.

## 새 쇼츠가 생길 때마다 하는 순서 (무료)

처음 설치를 마친 뒤에는 아래만 반복하면 됩니다. Claude 와의 대화는 Pro 구독에 포함이라 추가 비용이 없습니다.

```bash
python yt.py fetch
```
새로 올린 초안 쇼츠를 plan.csv 에 추가합니다.

```bash
python yt.py export
```
해시태그가 아직 없는 영상 목록이 메모장으로 열립니다. 전체 복사해서 Claude 대화창에 붙여넣고 아래처럼 요청하세요.
> "이 쇼츠들 설명란 해시태그랑 검색 태그 써줘. `video_id|설명 본문|#해시태그들|검색 태그` 형식으로, 영상당 한 줄로."

```bash
python yt.py import
```
처음 실행하면 빈 `tags.txt` 가 메모장으로 열립니다. Claude 가 준 내용을 붙여넣고 저장(Ctrl+S)한 뒤 **한 번 더** 실행하면 plan.csv 에 채워집니다. 이미 설명을 써둔 영상은 그 글을 살리고 해시태그만 덧붙입니다.

```bash
python yt.py apply
```
미리보기로 확인합니다.

```bash
python yt.py apply --execute
```
유튜브에 반영합니다. 예약까지 걸려면 그 전에 `schedule` 을 실행하거나, plan.csv 의 `publish_at` 에 시간을 직접 적으세요.

## 예약 달력 보기

```bash
python yt.py calendar
```
채널의 롱폼 · 쇼츠 예약 일정과 이미 공개된 영상을 달력으로 만들어 브라우저로 엽니다 (`calendar.html`). 실행할 때마다 유튜브의 최신 상태를 읽어오고, 영상을 누르면 스튜디오 편집 화면이 열립니다. 데이터는 내 PC 에만 저장됩니다.

스튜디오에서 예약을 계속 바꾸는 중이라면 실시간 모드로 켜두세요. 1분마다 바뀐 예약이 달력에 반영되고, 브라우저도 보던 달·필터를 유지한 채 자동으로 새로고침됩니다. 끝낼 땐 cmd 창에서 Ctrl+C.

```
python yt.py calendar --watch
```

갱신 1번에 할당량은 영상 50개당 1 (영상 450개면 9) 정도라 몇 시간 켜둬도 괜찮습니다. 켜둔 뒤 새로 올린 영상은 끄고 다시 실행해야 들어옵니다.

## 쇼츠가 공개되면 자동으로 댓글 달기

예약해 둔 쇼츠가 공개되면 채널 이름으로 "풀영상은 쇼츠 하단에서 확인하실 수 있어요 👇" 같은 댓글을 답니다. 공식 API 를 사용합니다.

```bash
python yt.py auth
```
댓글 권한 때문에 처음 한 번만 다시 로그인합니다.

```bash
python yt.py comment
```
미리보기입니다. `--execute` 를 붙이면 실제로 댓글을 답니다. 이미 채널 댓글이 있는 영상은 건너뜁니다.

```bash
setup_comment_task.bat
```
윈도우 작업 스케줄러에 등록해서 매일 08:10, 18:10, 21:10 에 자동으로 실행합니다 (그 시간에 PC 가 켜져 있어야 함, 기록은 `comment_log.txt`). 끄려면 `remove_comment_task.bat`.

- 문구는 기본 3가지를 영상마다 돌아가며 씁니다 (같은 문구 반복은 스팸으로 보일 수 있음). 바꾸려면 `config.yaml` 에 `comment: {texts: ["문구1", "문구2"]}`.
- 영상마다 다르게 하려면 plan.csv 의 `comment` 열에 문구를 적고, 댓글을 달지 않으려면 `-` 를 적습니다.
- 댓글 고정은 API 로 안 되므로 필요하면 스튜디오에서 직접 고정하세요. 쇼츠 댓글 속 링크는 클릭되지 않습니다.

## 시청자 댓글 답글 (반자동, 무료)

```bash
python yt.py replies
```
최근 7일 동안 채널이 아직 답글을 안 단 시청자 댓글이 메모장으로 열립니다. 전체 복사해서 Claude 대화창에 붙여넣고 "답글 써줘" 라고 하세요. Claude 는 `댓글ID|답글` 형식으로 답하고, 스팸·욕설은 `댓글ID|-` 로 건너뜁니다.

```bash
python yt.py replies --import
```
처음엔 빈 `replies.txt` 가 열립니다. Claude 의 답글을 붙여넣고 저장한 뒤 다시 실행하면 미리보기 후 한 번에 답니다. 모든 답글 끝에 "구독 좋아요 하이프까지 해주시면 더 나은 건강 정보로 보답드리겠습니다." 가 자동으로 붙습니다 (`config.yaml` 의 `reply: {footer: "..."}` 로 변경).

특정 영상의 댓글 전부에 답글을 달려면 `python yt.py replies --video 영상주소`. 답글이 많으면 `python yt.py replies --import --limit 70` 처럼 나눠 달고 (남은 건 replies.txt 에 남아 다음에 이어짐), 답글 사이엔 기본 4초 간격을 둡니다. 답글 근거가 될 영상 자막은 `python yt.py transcript 영상주소` 로 받습니다.

써둔 답글을 매일 조금씩 자동으로 달려면 `setup_replies_task.bat` 을 한 번 실행하세요. 매일 20:30 에 `replies.txt` 에서 20개씩, 60초 간격으로 답니다 (기록은 `replies_log.txt`, 끄려면 `remove_replies_task.bat`).

답글 원칙: 공감 댓글엔 공감, 전문적인 질문은 제공된 롱폼(원장님 말씀) 내용 안에서만 답하고 그 밖의 개인 증상·약·진단 질문은 전문의 상담을 권합니다.

## 1. 설치 (윈도우 PC, 최초 1회)

1. [python.org](https://www.python.org/downloads/) 에서 Python 설치
   - **Python Install Manager** 로 설치했다면, 설치 후 검은 창에 질문이 나옵니다. 모두 `y` 입력 후 Enter 하세요. (PATH 추가, 최신 Python 설치)
   - 예전 방식 설치 파일이라면 첫 화면에서 **Add python.exe to PATH** 를 체크하세요.
2. 코드 받기: 깃허브 저장소 페이지 → 초록색 **Code** 버튼 → **Download ZIP** → 받은 ZIP 우클릭 → **모두 압축 풀기**
3. 명령 프롬프트 열기: 압축 푼 폴더 안의 `youtube-scheduler` 폴더로 들어가서, 탐색기 맨 위 **주소창**을 클릭하고 `cmd` 입력 후 Enter. 그 폴더 위치로 검은 창이 열립니다.
4. 필요한 패키지 설치:

```bash
python -m pip install -r requirements.txt
```

5. 설정 파일 복사 후 메모장으로 내 채널에 맞게 수정:

```bash
copy config.example.yaml config.yaml
```

## 2. Google Cloud 설정 (최초 1회, 약 10분)

1. https://console.cloud.google.com 접속 → 상단에서 **새 프로젝트** 만들기
2. **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용**
3. **API 및 서비스 → OAuth 동의 화면**. 화면 이름이 **Google 인증 플랫폼(Google Auth Platform)** 으로 바뀌어 있을 수 있습니다.
   - **시작하기** → 앱 이름, 사용자 지원 이메일 입력

   - **대상(Audience)** 메뉴 → **테스트 사용자 → + Add users** → 내 유튜브 채널의 구글 계정 추가 → 저장
4. **클라이언트(Clients)** 메뉴 → **+ 클라이언트 만들기**. 예전 화면이라면 **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID** 입니다.
   - 애플리케이션 유형: **데스크톱 앱** → 만들기
   - **JSON 다운로드** → 파일 이름을 `client_secret.json` 으로 바꿔 이 폴더(`yt.py` 가 있는 곳)에 넣기
   - 윈도우가 확장자를 숨기는 경우 `client_secret.json.json` 이 되기 쉽습니다. 이름은 **`client_secret`** 까지만 입력하세요.
5. 연결 테스트:

```bash
python yt.py auth
```

브라우저가 열리면 채널 계정으로 로그인합니다. 브랜드 계정이라면 해당 채널을 선택하세요.
'확인되지 않은 앱' 경고가 나오면 **고급 → (앱 이름)으로 이동** 을 누르면 됩니다. 내가 만든 내 앱이라 괜찮습니다.

> - `client_secret.json`, `token.json` 은 비밀번호와 같습니다. 남에게 보내거나 깃허브에 올리지 마세요. (`.gitignore` 로 막아둠)
> - 테스트 모드 앱은 로그인이 약 7일마다 만료됩니다. 만료되면 `token.json` 을 지우고 `python yt.py auth` 를 다시 실행하세요.

## 4. 사용법

### ① 쇼츠 목록 가져오기

```bash
python yt.py fetch
```

채널의 **비공개** 쇼츠(3분 이하)를 `plan.csv` 로 가져옵니다. 다시 실행해도 내가 적어둔 내용은 지워지지 않고, 새 영상만 아래에 추가됩니다.

> **스튜디오 '초안' 상태 영상**은 API 에 보이지 않거나 수정이 막힐 수 있습니다.
> 개수가 모자라면, 스튜디오에서 초안을 열어 **공개 상태: 비공개** 로 저장한 뒤 다시 `fetch` 하세요.

옵션:
- `--include-public` 은 이미 공개된 영상도 포함합니다. 제목·설명 수정만 가능하고 예약은 안 됩니다.
- `--all-types` 는 롱폼도 포함합니다.

### ② plan.csv 채우기 (엑셀)

| 열 | 내용 | 누가 |
|---|---|---|
| `video_id`, `current_*`, `duration_sec`, `is_short`, `studio_link` | 유튜브 현재 상태 | 자동 (fetch 때마다 갱신) |
| `memo` | (선택) 제목만으로 안 드러나는 내용 한 줄. 예: `등 통증 강조, 50대 대상` | 나 |
| `related_longform` | 이 쇼츠를 연결할 롱폼 제목이나 링크 | 나 |
| `new_title` | 바꿀 제목 (비우면 그대로 둠, 기본적으로 generate 는 안 씀) | 나 |
| `new_description` | 바꿀 설명 전체, 해시태그 포함 (비우면 그대로 둠) | generate 또는 나 |
| `new_tags` | 검색 태그, 쉼표로 구분 (비우면 그대로 둠) | generate 또는 나 |
| `publish_at` | 예약 공개 시간 `2026-11-10 18:00` (한국 시간) | schedule 또는 나 |
| `apply_status` | 반영 결과 (완료/실패 사유) | 자동 |

Claude 는 **현재 제목**과 기존 설명을 보고 주제를 파악합니다. 제목이 내용을 잘 담고 있다면 `memo` 는 비워도 됩니다. 영상에 없는 내용은 지어내지 않도록 해뒀습니다.

> 엑셀에서 저장할 때는 **CSV UTF-8 (쉼표로 분리)** 형식을 유지하세요. 이 도구를 실행할 때는 엑셀에서 파일을 닫아주세요.

### ③ 설명란 해시태그 · 검색 태그 작성

```bash
python yt.py generate --limit 3
```

처음엔 3개만 써보고 결과가 마음에 들면 `--limit` 없이 전체를 실행하세요.

Claude 는 영상마다 **이 영상이 꼭 필요한 시청자**(예: "소화불량과 등 통증이 있는 50~60대")를 먼저 정합니다. 그다음 그 사람이 실제로 검색할 말로 해시태그를 고릅니다.
- 1번 해시태그: 핵심 주제 (질환명·부위·운동명 등 가장 구체적인 것)
- 2번 해시태그: 시청자의 증상·고민·상황
- 그다음: 분야 키워드 (건강정보, 운동법 등)와 `#shorts`

화면에 영상별 **대상 시청자**와 **해시태그**가 출력되니, 대상이 엉뚱하면 `memo` 를 채우고 `--overwrite` 로 다시 작성하세요.

설명란은 아래 순서로 구성됩니다:
```
(본문: 이미 써둔 설명이 있으면 그대로 유지, 없으면 Claude 가 2~3문장 작성)

(config.yaml 의 description_footer 고정 문구)

#핵심주제 #시청자고민 #분야 #shorts
```

검색 태그(`new_tags`, 설명란에는 안 보임)에는 동의어, 다른 표기, 검색 문구가 들어갑니다. 예: `췌장암 초기증상`

옵션:
- `--overwrite` 는 이미 쓴 것도 다시 작성합니다.
- `--only 영상ID,영상ID` 는 특정 영상만 작성합니다.

고정 해시태그, 해시태그 개수, 고정 문구는 `config.yaml` 의 `writing` 에서 바꿉니다.

### ④ 예약 시간 배정

```bash
python yt.py schedule --start 2026-11-10 --times 18:00,20:00,22:00
```

`plan.csv` 의 위에서부터 차례로 11/10 18:00, 20:00, 22:00, 11/11 18:00 … 식으로 배정합니다.

- `publish_at` 이 이미 있는 영상은 건드리지 않습니다. 그 시간도 피해서 배정합니다.
- 전체 일정을 다시 짜려면 `--overwrite` 를 붙입니다.
- 순서를 바꾸고 싶으면 엑셀에서 행 순서를 바꾸거나 `publish_at` 을 직접 고치면 됩니다.

### ⑤ 검사 → 미리보기 → 반영

```bash
python yt.py check
```

```bash
python yt.py apply
```

```bash
python yt.py apply --execute --limit 1
```

```bash
python yt.py apply --execute
```

```bash
python yt.py verify
```

- `check` 는 제목 100자 초과, `< >` 사용, 설명 5000바이트 초과, 해시태그 과다, 지난 시간, 시간 겹침을 잡아냅니다.
- `apply` 는 **미리보기만** 합니다. 영상별로 무엇이 어떻게 바뀌는지 보여줍니다.
- `apply --execute --limit 1` 로 **먼저 1개만** 실제 반영해 보고 스튜디오에서 확인하세요.
- 확인됐으면 `apply --execute` 로 전체를 반영합니다. 반영 전 원래 값은 `backups/` 폴더에 저장됩니다.
- `verify` 는 유튜브에 실제로 들어갔는지 다시 확인합니다.

이미 같은 값인 영상은 자동으로 건너뜁니다. 중간에 끊겨도 다시 실행하면 남은 것만 처리합니다.

### ⑥ 관련 동영상(롱폼) 연결 체크리스트

```bash
python yt.py linklist
```

`related_longform` 을 적어둔 쇼츠들로 `longform_checklist.md` 를 만듭니다. 스튜디오 링크를 하나씩 눌러 **관련 동영상** 을 선택하면 됩니다.

### 일정 바꾸기

`plan.csv` 의 `publish_at` 을 고치고 `apply` → `apply --execute` 하면 됩니다. 아직 공개되지 않은 예약 영상이면 언제든 바꿀 수 있습니다.

## 알아둘 점

- **할당량**: 기본 하루 10,000 단위이고, 영상 1개 수정에 50 단위입니다. 하루 약 200개까지 수정할 수 있습니다. 넘으면 자동으로 멈추고, 다음 날 이어서 처리합니다.
- **예약 조건**: 유튜브 규칙상 한 번도 공개된 적 없는 비공개 영상만 예약할 수 있습니다. 공개·일부공개 영상은 도구가 예약을 거부합니다.
- **API 프로젝트 제한**: 새로 만든 API 프로젝트에 유튜브가 제한을 거는 경우가 있습니다. 예약 공개가 막힌다면 `apply_status` 에 사유가 남습니다. 그래서 첫 반영은 꼭 `--limit 1` 로 테스트하세요.
- **해시태그**: 3~5개를 권장합니다. 60개를 넘으면 유튜브가 해시태그를 전부 무시합니다.
