## 문서에 넣는 형식
- 원문 대사는 절대 수정하지 않는다.
- 답변을 의미 단위로 잘라 구간 앞에 `#번호` 줄을 넣는다.
- 구간 바로 아래에 `-> 프롬프트` 줄을 넣는다. 여러 장이면 `->` 줄을 여러 개 쓰고 마지막에 `-> 총 N장`.
- 번호는 부마다 #1부터 다시 시작한다 (예시 문서 방식).
- 소개 구간에는 이미지를 넣지 않는다. 각 부의 첫 질문(Q.1)부터 #1.

## 작업 규칙 (예시 문서 5개, 545구간·547프롬프트 분석)
분석 문서: 김용진·강형창·오은영·류은경(1KROChnfYXcFdjQPZ9D6V6xSzFSBdKoOKS3Fq8JVAmlY)·박수현(1j0syhUImD2jMeo-oAiho0jcpmcj2-dbeGFuQNEClUVo)

### A. 구간 나누기
1. 1~2문장마다 한 구간으로 나눈다. 원문 길이 중앙값은 약 150자이고, 300자를 넘으면 쪼갠다.
2. 이미지는 "그 이미지를 떠올리게 하는 문장" 바로 뒤에 붙인다. 구간 끝에 몰아 붙이지 않는다.
   그 뒤에 이어지는 부연·반복 문장은 `#` 없이 그대로 둔다 (예시 구간의 약 26%가 이 형태).
3. 이미지를 넣지 않는 곳: 자기소개, 인사, 촬영 사담, "네 답변 감사합니다", 같은 말을 되풀이하는 문장.
4. 번호는 부마다 #1부터 다시 시작한다.

### B. 실사냐 그래픽이냐 (실사 약 45 : 그래픽 약 55)
- 대사에 **구체적인 물건이나 음식 이름**이 나오면 → 그 물건의 실사 스톡 ("밥, 빵, 면 실제 스톡 연출", "커피, 술 스톡 이미지")
- **사람의 행동, 상황, 감정**이 나오면 → 인물 실사 (누가 + 어디서 + 표정)
- **원리, 과정, 숫자, 비교, 전문 용어**가 나오면 → 그래픽
- **비유**가 나오면 (송곳, 지하실 등) → 그 비유를 그대로 그린 그래픽
- 2장 이상은 구간의 5~10%만. "개념 그래픽 + 장면 실사"가 둘 다 꼭 필요할 때만 쓴다.

### C. 프롬프트 쓰는 법 (길이 중앙값 26자, 길어도 40자 안팎)
- 기본은 짧게 쓴다. 이미지 AI가 대본과 함께 보므로 "이 부분"으로 가리키면 된다.
  - 그래픽 기본형: "-> 이 부분을 단순 명료한 그래픽으로 연출"
  - 실사 기본형: "-> [누가] [무엇을 하는] 실사 연출" (예: "-> 식후 걷는 중년 실사 연출")
- 길게 쓰는 건 이럴 때만이다.
  - 구도가 중요할 때: "왼쪽은 ~, 우측은 ~", "순차적으로 A -> B -> C", "졸라맨이 가운데 ~"
  - 팩트나 워딩이 걸릴 때: "너가 팩트 체크하고 워딩 정리해서"
  - 표정이나 연기가 핵심일 때: "짜증이 잔뜩 난 표정", "생생하게, 몰입하도록"
- 자주 쓰는 표현: 단순 명료한 / 간단 명료한, 100명 중 100명이 이해하게, 텍스트는 최소로, 실제 사진처럼, 순차적으로, 비교 그래픽, 1장/2장/총 N장
- 인물은 나이대(청년/중년/젊은 여성/중년 남성)를 꼭 쓰고, 필요하면 "한국인, 한국 배경"을 붙인다.
- 그래픽 톤은 아래 "그래픽 톤앤매너"를 따르되, 프롬프트에 매번 길게 반복하지 않는다.

### E. 과거 버전 2개에서 확인한 것 (이진복 2부 1OhW8c68ZLAC61HNU-7VEPmJBcA3IaennhLZaTQNKExg, 이종현 1lpUEju5O3m7a0uyig1_xlR4pZn7uGxLROMV3Z_NJc14)
- 변화 흐름: 이종현(가장 초기, "스톡"·"단순 명료 그래픽" 한 단어 수준) → 이진복(아주 길고 구체적) → 최근 5개(짧고, 필요한 곳만 구체적). **최근 방식을 기준으로 한다.**
- 이진복 버전에서 가져올 것 (실사를 구체적으로 쓸 때 참고):
  - 실사는 "끌리게" 쓴다: "최대한 먹고 싶게", "매우 맛나게 먹음", "최대한 기름져 보이게"
  - 한국 맥락을 붙인다: "대한민국 길거리", "한국인 어머니", "한국에서 가장 유명한 ~"
  - 대사 속 일화나 역사 이야기는 그 장면을 실사로 재현한다 ("교회에서 시리얼을 나눠주는 모습", "전쟁 중 창고에 쌓인 통조림")
  - 제품 이미지에는 "텍스트 오타 없이"를 붙인다
  - 그래픽 문구는 내가 대충 쓰고 "내가 쓴 대로 하지 말고 더 간단 명료하게"라고 맡긴다 → 그래픽 안 문구는 내가 다듬어서 정한다
  - 프롬프트 → 이어지는 부연 문장 순서(문장 바로 뒤에 붙이는 방식)는 이때부터 같다
- 이종현 버전처럼 `#`만 있고 프롬프트가 빈 구간은 미완성 초안이다. 따라하지 않는다.

### D. 피해야 할 것 (내 1부 초안과 비교해서 나온 것)
- 프롬프트가 너무 길다 (내 초안 중앙값 111자, 사용자 26자). 그래픽 안의 문구를 내가 다 정해 넣지 않는다.
- 2장짜리를 남발했다 (약 35%).
- 이미지를 구간 끝에만 붙였다 → 이미지를 떠올리게 하는 문장 바로 뒤에 붙인다.

## 사용자 기준 (피드백 누적)
1. 어렵거나 복잡한 내용, 전문 용어 → 그래픽으로 쉽게 풀기.
2. 눈으로 보여주면 되는 장면 → 실사 이미지 (인물은 한국인, 나이대 명시).
3. 채팅으로 보여줄 때는 항상 "대본 원문 + 그 아래 프롬프트" 형태로 (프롬프트만 따로 X).
4. 비교가 되는 내용은 실사도 비포/애프터로 보여주면 좋다 (예: 치아 모형으로 볼록 vs 평평).
5. 대사에 묘사된 동작(예: 위아래 치아가 맞물려 씹음)은 그 장면 실사를 추가.

## 그래픽 톤앤매너
- 흰색/아주 연한 회색 배경, 넓은 여백, 16:9 (1920×1080)
- 검은 선 미니멀 라인 일러스트, 무채색. 강조는 연한 회색만
- 캐릭터: 동그란 머리 + 선 몸 졸라맨, 단순한 표정
- 감정 기호: 번개(스트레스), 엉킨 실타래(혼란), 방사선(강조), 하트(따뜻함)
- 텍스트: 한글 고딕. 제목은 굵은 검정, 설명은 얇은 회색 짧은 문장
- 구성: 좌우 비교(가운데 얇은 세로선), 화살표 흐름(1. → 2.), 둥근 말풍선(얇은 회색 테두리 + 연결선)

## 진행 상황
- 1부 전체를 새 규칙(A~E)으로 다시 써서 작업 문서에 반영 완료: **#1~#50** (Q.1~Q.8, 소개 구간 제외).
  - 프롬프트 52개 (그래픽 33 : 실사/스톡 19), 2장짜리 구간 2개, 프롬프트 길이 중앙값 약 37자.
  - 사용자 검토 대기. 이상 없으면 2~4부도 같은 방식으로 맡기겠다고 함.
  - **작업 문서가 최신본이다.** 아래 "확정된 1부 #1~#6", "1부 #7~#20 초안"은 옛 버전(31구간)이라 더 이상 쓰지 않는다.
- 다음: 1부 피드백 반영 → 2~4부 (부당 약 50구간 기준, 2부는 Q.1~Q.12, 3부 Q.1~Q.8, 4부 Q.1~Q.7).

## 문서 반영 방법 (Google Docs 커넥터)
- mobilebasic 보기(https://docs.google.com/document/d/<ID>/mobilebasic)로 본문 텍스트를 받아 구간을 정한다.
- update_doc의 replaceAllText로 구간 경계의 짧은 고유 문자열을 "원문\n-> 프롬프트\n#N\n원문" 형태로 바꿔 넣는다.
  (문서 전체에서 1회만 나오는 앵커인지 먼저 확인. 결과의 occurrencesChanged가 모두 1이어야 함)
- 반영 후 mobilebasic을 다시 받아 원문이 바뀌지 않았는지 확인한다.
- 다시 쓸 때(1부 재작업에서 쓴 방법): read_doc으로 JSON을 받아 문단별 startIndex를 얻고,
  ① 기존 `#N`·`->` 줄만 deleteContentRange로 지움(뒤에서부터), ② 문서를 다시 읽어 깨끗한 문단 인덱스를 얻은 뒤,
  ③ 구간 시작 문구/프롬프트를 붙일 문장 끝 문구를 정하고 insertText를 인덱스 큰 것부터 넣는다.
  requiredRevisionId를 걸어 중간에 문서가 바뀌면 실패하게 한다. 넣기 전에 파이썬으로 시뮬레이션해서 원문 동일, 번호 연속을 확인한다.

## 확정된 1부 #1~#6 프롬프트
(소개 구간은 이미지 없음)

#1 (Q.1 "일단 첫 번째로는 잇몸과 관련된 … 쪼그라드는 형태로 진행이 되거든요")
-> 좌우 비교 그래픽. 가운데 얇은 세로선, 왼쪽 제목 "젊은 잇몸", 오른쪽 제목 "나이 든 잇몸". 치아 단면을 선으로 단순하게, 오른쪽은 잇몸·뼈 선이 아래로 내려가 있음. 하단 회색 설명: 왼쪽 "치아를 단단히 감싸고 있어요", 오른쪽 "잇몸과 뼈의 높이가 낮아져요"

#2 ("그러면 치아는 멀쩡히 있더라도 … 그 공간에 음식물이 끼게 됩니다")
-> 단순 명료한 그래픽. 상단 굵은 제목 "블랙 트라이앵글". 치아 2개를 선으로 그리고 그 사이 잇몸이 내려가 생긴 삼각형 빈틈만 연한 회색으로 강조, 주변에 방사선. 하단 회색 설명 "잇몸이 내려가 치아 사이에 생긴 틈, 음식물이 끼기 쉬워요"

#3 ("자연스러운 노화에 의해서 … 첫 번째 요인이라 볼 수 있고요")
-> 화살표 흐름 그래픽 1장. 상단 제목 "잇몸이 더 빨리 내려가는 이유". 왼쪽에 아이콘 3개 세로 나열: 잇몸병, 너무 센 양치, 잘못된 양치 습관 → 화살표가 오른쪽으로 모여 "잇몸 내려감 가속"
-> 거울 앞에서 칫솔로 이를 박박 세게 닦는 한국인 중년 실사 1장
-> 총 2장

#4 ("두 번째로는 치아와 관련된 요인인데 … 그 마모가 더 심해지고요")
-> 위아래 치아가 맞물리면서 음식을 씹는 입 안 클로즈업 실사 1장. 어금니로 음식을 꽉 깨무는 순간
-> 얼음이나 견과류 같은 딱딱한 음식을 와작 씹는 한국인 중년 남성 실사 1장
-> 총 2장

#5 ("일반적으로는 우리가 치아는 볼록볼록한 … 빈번하게 발생합니다")
-> 비포/애프터 실사 1장. 치아 모형(임플란트·틀니 모형 느낌)으로 연출. 왼쪽은 볼록볼록한 돌기가 살아 있는 어금니, 오른쪽은 닳아서 윗면이 평평해진 어금니. 흰 배경에 깔끔하게
-> 좌우 비교 그래픽 1장. 왼쪽 제목 "원래 치아", 오른쪽 제목 "닳은 치아". 왼쪽은 볼록볼록한 어금니 위 음식물(회색 덩어리)이 화살표 따라 빠져나감, 오른쪽은 평평한 어금니에 음식물이 콱 박혀 방사선 강조. 하단 회색 설명: 왼쪽 "음식물이 자연스럽게 빠져나가요", 오른쪽 "음식물이 그대로 박혀요"
-> 총 2장

#6 ("세 번째로는 오히려 젊은 층에서 … 현상이라고 볼 수 있겠습니다")
-> 단순 명료한 그래픽 1장. 사랑니를 선으로 그리고 잇몸이 반쯤 덮고 있음. 잇몸과 치아 사이 틈을 연한 회색으로 강조하고 음식물이 끼는 모습. 하단 회색 설명 "잇몸이 반쯤 덮인 사랑니, 틈 사이에 음식물이 끼어요"
-> 어금니 안쪽이 불편해서 볼을 손으로 감싸고 찡그리는 한국인 20대 청년 실사 1장
-> 총 2장

## 1부 #7~#20 초안 (피드백 대기)

#7 (Q.2 "깊게 박히는 요인에 기여하는 것은 … 빈번하게 좀 발생하고 있습니다")
-> 화살표 흐름 그래픽. 상단 제목 "치아는 2:1로 맞물려요". 위쪽 치아 2개 사이로 아래쪽 뾰족한 치아 1개가 맞물리는 모습. 뾰족한 끝이 음식물(회색 덩어리)을 위 두 치아 사이로 밀어 넣는 걸 화살표로. 하단 회색 설명 "뾰족한 치아가 음식물을 틈 사이로 밀어 넣어요"

#8 ("그래서 환자분들께 치아가 너무 뾰족하면 … 해결을 해드리고 있는 편입니다")
-> 좌우 비교 그래픽 1장. 왼쪽 제목 "송곳처럼 뾰족한 치아"(음식물을 콱 밀어 넣음), 오른쪽 제목 "살짝 다듬은 치아"(음식물이 빠져나감). 하단 회색 설명 "간단한 조정으로 줄일 수 있어요"
-> 치과 진료실에서 치과의사가 환자 어금니를 살짝 다듬어 조정하는 실사 1장. 편안한 표정의 한국인 중년 환자
-> 총 2장

#9 (Q.3 "일단 임플란트는 저희가 … 조금 다르게 생겼거든요")
-> 좌우 비교 그래픽. 왼쪽 "자연치아", 오른쪽 "임플란트". 둘 다 머리·몸통·뿌리 3부분을 선으로 그리고 라벨. 임플란트 뿌리는 나사 모양. 하단 회색 설명 "머리는 비슷하지만 뿌리 모양이 달라요"

#10 ("그러다 보니까 머리 부분은 … 첫 번째는 임플란트 구조에서 오는 차이가 있고요")
-> 단순 명료한 그래픽. 자연치아 2개 사이 임플란트 1개. 임플란트 몸통이 잘록해 양옆에 생긴 빈틈을 연한 회색으로 강조, 음식물이 낌. 상단 제목 "몸통이 잘록한 임플란트", 하단 회색 설명 "옆 치아와 틈이 넓어져 음식물이 껴요"

#11 ("두 번째로는 임플란트 하고 나서 몇 년 … 음식물이 끼는 경우가 생길 수 있고요")
-> 좌우 비교 그래픽. 왼쪽 "자연치아": 뿌리와 뼈 사이 얇은 인대 선 + 작은 흔들림 표시(〰). 오른쪽 "임플란트": 나사가 뼈에 바로 붙어 있음 + 자물쇠 아이콘. 하단 회색 설명: 왼쪽 "인대가 있어 미세하게 움직여요", 오른쪽 "인대가 없어 전혀 움직이지 않아요"

#12 ("두 번째로는 이게 더 핵심적인 내용인데 … 삼, 사년 지나면 굉장히 많이 오세요")
-> 비포/애프터 그래픽. 치아를 옆에서 본 일렬 그림. 왼쪽 "임플란트 직후": 빈틈없이 붙어 있음. 오른쪽 "3~4년 후": 자연치아들이 앞쪽으로 이동(← 화살표), 제자리에 있는 어금니 임플란트 앞에 빈틈이 생겨 연한 회색 강조. 하단 회색 설명 "자연치아는 앞으로 이동, 임플란트는 그대로"

#13 ("그래서 이거는 저는 임플란트를 첫날에 마무리할 때 … 원칙으로 하고 있습니다")
-> 치과 진료실에서 임플란트 치료를 마친 한국인 중년 환자에게 치과의사가 치아 모형을 보여주며 설명하는 실사. 환자는 고개를 끄덕이며 듣는 모습

#14 (Q.4 "제가 지금까지 설명해 드린 걸 … 그런 부위들이 있거든요")
-> 단순 명료한 그래픽. 상단 제목 "한 입 안에 둘 다 있어요". 치아 한 줄(아치형)을 선으로, 평평하게 닳은 치아에 "평평 → 음식물이 박힘", 뾰족한 치아에 "뾰족 → 음식물을 밀어 넣음" 회색 라벨. 가운데에 물음표 달고 고개를 갸웃하는 졸라맨 작게

#15 ("그래서 이거는 제 설명만으로는 … 부연 설명을 드릴게요")
-> 치과 진료실에서 모니터에 띄운 구강 사진을 치과의사가 가리키며 한국인 중년 환자에게 설명하는 실사

#16 (Q.5 "이거는 조금은 슬픈 소식이지만 … 일단 설명을 드리거든요")
-> 화살표 흐름 그래픽. 상단 제목 "틈을 메우면 생기는 일". 4단계 가로 나열: 벌어진 틈 → 메우는 치료 → 잇몸이 또 내려감 → 다시 수리, 마지막에서 처음으로 돌아가는 원형 화살표(반복). 하단 회색 설명 "차라리 틈을 열어두는 게 장기적으로 유리해요"

#17 ("그래서 차라리 이걸 우리가 받아들이고 … 대안을 삼는 게 좋다고 봐요")
-> 욕실 세면대 앞에서 치간칫솔로 치아 사이를 닦는 한국인 중년 실사 1장
-> 치간칫솔과 치실을 흰 배경에 깔끔하게 나란히 놓은 실사 스톡 1장
-> 총 2장

#18 (Q.6 "우리가 틈새가 오히려 완전히 넓은 분들은 … 이제 실천해야 되는데")
-> 단순 명료한 그래픽. 상단 제목 "틈 크기별로 이렇게 빼세요". 3칸 나란히(얇은 세로선 구분). 위: 넓은 틈 / 애매한 틈 / 좁은 틈. 아래: 물방울 "물로 헹구기" / 치간칫솔 "치간칫솔" / 치실 "치실"

#19 ("치실 쓰는 게 사실 치간칫솔보다 … 쉽지 않단 말이죠")
-> 거울 앞에서 긴 치실을 손가락에 감아 어금니 쪽에 넣으려다 어려워서 찡그리는 한국인 40대 실사

#20 ("그래서 요즘에는 손잡이가 달린 치실이 … 더 좋다고는 생각은 들거든요")
-> 좌우 비교 실사 1장. 왼쪽 손잡이 달린 치실(Y자형) 제품, 오른쪽 손가락에 감은 긴 치실. 흰 배경에 깔끔하게
-> 좌우 비교 그래픽 1장. 왼쪽 "손잡이 치실" / 회색 설명 "쉽고 편해요", 오른쪽 "손에 감는 치실" / 회색 설명 "더 깊이까지 닿아요" + 오른쪽 위 작은 "추천" 배지
-> 총 2장
